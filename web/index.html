Результат — подсказка для проверки человеком, а не юридическое или дисциплинарное заключение. Сервис не делает выводов о том, чего не видно на видео: суммах, проводках, сверках.

Что делает сервис

Сервис просматривает видеозапись кассового помещения и ищет визуально наблюдаемые действия, которые могут указывать на нарушение кассовой дисциплины. Для каждого найденного эпизода он показывает тип, таймкод, 1–3 кадра, краткое описание увиденного и пункт нормативного акта Республики Казахстан.

Как устроен анализ

  1. Поиск. Визуально-языковая модель просматривает ролик окнами по 10 секунд (2 кадра в секунду) и отмечает эпизоды из перечня типов ниже, а также «иное возможное нарушение».
  2. Повторная проверка. Эпизоды типов, где модель чаще ошибается (уход с рабочего места, телефон, еда, манипуляции с купюрами, идентификация клиента, ключ от сейфа), проверяются узким вопросом на увеличенных кадрах нужной области.
  3. Результат. Обоснование и норматив берутся из каталога правил; модель добавляет только описание того, что видно в кадре.

Модель — Qwen3-VL-30B-A3B (лицензия Apache-2.0), работает через vLLM на сервере команды без доступа в интернет. Облачные AI-сервисы не используются; лица не распознаются; звук не анализируется.

Распознаваемые типы нарушений

Связь пункта с видео: прямое требование — пункт прямо регулирует наблюдаемое действие; трактовка — пункт регулирует близкую норму, связь с видео — интерпретация команды.

Нормативные источники

    Ограничения

    • Сервис выдаёт подсказку для проверяющего, а не заключение. Если вывод требует невидимых данных (сумма, проводка, сверка), формулировка остаётся «требует сверки».
    • Мелкие детали (ключ в замке сейфа, удостоверение против купюры) на записи 464×848 различаются ненадёжно.
    • Чаще всего ложные срабатывания — «не проведена идентификация» и «уход с рабочего места»; таймкод входа и выхода людей может отличаться от начала действия на 2–5 секунд.
    • Модель не обучалась на конкретных роликах и не привязана к координатам в кадре, но качество на сильно другом ракурсе не измерено.

    API для интеграции

    Доступ по ключу в заголовке X-API-Key. Обработка асинхронная: загрузка возвращает job_id, результат забирается по нему.

    curl -X POST /api/v1/analyze -H "X-API-Key: <ключ>" -F "file=@video.mov"
curl /api/v1/jobs/<job_id> -H "X-API-Key: <ключ>"

    Статусы: processing, done, failed. Полное описание — на странице /docs.

# ForteBank Datathon 26 — контроль кассовой дисциплины по видео

AI-сервис: загружаете видеозапись работы кассира — получаете вердикт, возможные нарушения с типом,
таймкодом, кадрами-доказательствами, описанием и ссылкой на норматив РК. Все модели работают локально
внутри сервиса (Qwen3-VL через vLLM на собственном GPU-сервере), без облачных AI-API.

| Документ | Для кого |
|---|---|
| [ml/README.md](ml/README.md) | архитектура модели, метрики, типы нарушений и нормативы, ограничения, соответствие условиям кейса |
| [BACKEND.md](BACKEND.md) | запуск сервера локально и на GPU, контракт API, деплой для жюри, чек-лист |

```
app/        сервер (FastAPI): API по разделу 10 ТЗ, очередь заданий
web/        веб-интерфейс
ml/         распознавание: ml/cashier — продукт, ml/experiments — оценка, ml/remote — GPU-сервер
eval/       разметка датасета командой (сами видео в репозиторий не входят)
```

# ForteBank Datathon 26 — контроль кассовой дисциплины по видео

AI-сервис: загружаете видеозапись работы кассира — получаете вердикт, возможные нарушения с типом,
таймкодом, кадрами-доказательствами, описанием и ссылкой на норматив РК. Все модели работают локально
внутри сервиса (Qwen3-VL через vLLM на собственном GPU-сервере), без облачных AI-API.

## Как пользоваться

**Веб-интерфейс** — открыть адрес сервиса, перетащить файл `.mov` в окно загрузки. Сервис покажет этап
обработки, затем вердикт («Нарушение не обнаружено» / «Обнаружены признаки возможных нарушений»), плеер с
отметками эпизодов и карточку на каждый эпизод: таймкод, тип, что видно на видео, почему это может быть
нарушением, пункт нормативного акта и 1–3 кадра. Нажатие на таймкод или кадр перематывает видео к моменту.
Раздел «Как это работает» — перечень типов нарушений, источники, ограничения и описание API.

**API** (раздел 10 ТЗ) — ключ в заголовке `X-API-Key`:

```bash
curl -X POST https://<адрес>/api/v1/analyze -H "X-API-Key: <ключ>" -F "file=@video.mov"   # → {"job_id": ...}
curl https://<адрес>/api/v1/jobs/<job_id> -H "X-API-Key: <ключ>"                           # processing / done / failed
```

Интерактивное описание API — `https://<адрес>/docs`.
